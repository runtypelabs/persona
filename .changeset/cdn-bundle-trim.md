Shrink the CDN bundle (`index.global.js`) from 156.3 to 129.4 KiB Brotli (195.6 → 163.6 kB gzip). The `*.global.js` bundles get a second terser minification pass (frequency-ordered identifier mangling compresses better), and TypeScript `private` class members are now native `#private` fields so their names minify too. Code that only runs after something happens now loads from lazy sibling chunks next to `index.global.js`: the SSE stream processor (`client-stream.js`, fetched in parallel with each request), visitor-history REST and the history shell (`client-history.js`, `history-shell.js`), approval / ask-user-question / WebMCP resolve paths (`session-actions.js`), the ask-user sheet handlers and context-mention orchestrator (`ui-extras.js`), plus voice wiring (`voice-runtime.js`) and the history confirm dialog (`history-view.js`). Self-hosted CDN deployments must serve these files alongside `index.global.js`. npm (ESM/CJS) consumers keep everything bundled and registered up front. Build output now targets ES2022 (native private fields: Chrome 84+, Firefox 90+, Safari 15+).
