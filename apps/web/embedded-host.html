Embedded assistants

Test independent widgets, switch conversations, and move a widget into a modal. Replies are mocked.

Controls apply to the selected assistant. Changing defaults restarts both widgets; reloading clears demo history.

Things to try
  • Restore a conversation: Open Project brief, write a draft, attach a file, and scroll up. Switch to Release notes and back to restore the draft, attachments, and reading position.
  • Continue in the background: Select Continue in background, send a message, then switch conversations. Return to see the reply. The local simulation runs for about 15 seconds.
  • Compare loading indicators: Set History delay to Slow, choose Spinner or Skeleton bubbles, then switch conversations.
  • Move a widget: Select Move to modal to keep using the same conversation in a different container.

No background tasks.

Additional test controls

Use + for files and context, or Concise for shorter replies. Responsive tools move into + at narrow widths. V4 presets use a fixed layout.
