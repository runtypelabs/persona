Two assistants, one host

Independent widgets with shared host controls. Messages stay local; no API key is needed. A writing row, a quiet toolbar, and a shared menu for context and tools. Each assistant keeps its own conversation and settings.

Host API and lifecycle controls

Use + to attach a file or add sample context, and Concise for shorter answers. Responsive tools fold into + as the host narrows and return when it grows. Layout, scenario, theme, and width apply to the selected assistant; changing defaults restarts both. V4 comparison presets pin their named layout.
