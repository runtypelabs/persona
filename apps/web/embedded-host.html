Two assistants, one host

Independent widgets with shared host controls. Messages stay local; no API key is needed. A writing row, a quiet toolbar, and a shared menu for context and tools. Each assistant keeps its own conversations and settings.

Choose Project brief, type an unsent draft, attach a text file, and scroll up. Open Release notes, write a different draft, then return to Project brief: its draft, attachments, and reading position return. Try moving the same widget to the modal between switches. Run a local reply to test switching while busy. History opens simulate a short loading delay. History and drafts last for this page visit; changing defaults restarts both widgets.

To try background work, open Project brief, choose Continue in background, and send a message. Switch to Release notes while the reply is streaming, then return to catch up. Named conversations use a local simulated durable job; it runs for about 15 seconds even after its stream disconnects. Reloading the page resets this simulation.
