UI SDK Agent Bridge

The settings form below is built with UI SDK web components. Its agent bridge publishes three WebMCP tools, and Persona's agent uses them to read and change the form. The page defines no tools of its own.

Notes


      

        
How it works

        
UI SDK components carry their own state and actions. createAgent() builds a bridge over every component on the page, and registerTools() publishes it on document.modelContext as three tools: snapshot (list components, values and actions), query (list a component's choices) and act (run steps such as setValue or press). With webmcp: { enabled: true }, Persona sends those tools to the agent each turn and runs the calls it gets back on the page.

      


      

        
Three approval tiers

        
Reads and field edits run without a prompt. webmcp.autoApprove approves snapshot, query, and any act call whose steps only edit fields. Edits stay unsaved and show in the activity log.

        
Button presses ask first. An act call with a press step shows Persona's approval bubble, with the steps described by approval.formatDescription.

        
Marked controls ask on the page. The Delete workspace button carries data-agent-confirm. The bridge hands that step to the page's allow callback, which opens its own dialog with the sentence from the mark. This guard belongs to the page, so it holds for every WebMCP consumer and no widget setting skips it.

      


      

        
Private values

        
The Tax ID field carries data-agent-secret. The agent can fill it, but the snapshot, tool results and activity log show [redacted] in place of its value.

      


      

        
Observe and undo

        
agent.subscribe() reports each change with its source: agent, mouse, keyboard and so on. createHistory(agent).undoSource("agent") restores the fields the agent changed and keeps the person's own edits.

      


      

        
Config snippet

        

// Install the WebMCP polyfill before registering tools
import "@mcp-b/global";
import { createAgent, registerTools } from "@ui-sdk/web/agent";

const bridge = createAgent();
registerTools(bridge, {
  // Steps on data-agent-confirm controls arrive with step.confirm
  allow: (step, { signal }) =>
    step.confirm ? askPerson(step.confirm, signal) : true,
});

// Persona: send the tools to the agent, ask before presses
{
  webmcp: {
    enabled: true,
    autoApprove: (info) =>
      isAutoApprovedBridgeCall(info.toolName, info.args, bridge.snapshot()),
  }
}
