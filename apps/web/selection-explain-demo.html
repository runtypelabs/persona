Select-to-Explain

A host-page toolbar appears when you select article text. It quotes the selection into the widget with controller.setQuote(), then sends it or focuses the composer.

Try it

Highlight a sentence or two in the article. Then pick an action:

  • Explain this — sends the selection with a canned prompt.
  • Ask about it — quotes the selection. You type the question.

The echo backend replies with what it received.

    Field Notes

    How Espresso Extraction Works

    Nine bars of pressure, thirty seconds, and a surprising amount of chemistry: what actually happens inside the puck.

    💡 Highlight any passage below to ask the assistant about it.

    Solubles in a hurry

    Espresso is a forced-percolation brew: hot water at roughly nine bars of pressure is pushed through a compacted bed of finely ground coffee, dissolving and emulsifying its soluble material in well under a minute. Extraction yield — the percentage of the dry grounds' mass that ends up in the cup — typically lands between 18 and 22 percent. Below that range the shot tastes sour and thin because the fast-dissolving fruit acids arrive first; above it, slow-moving bitter phenolics and dry-tasting melanoidins dominate.

    The order of dissolution is the whole game. Acids and simple sugars give up quickly; caramelized sugars take longer; the harsh, papery compounds emerge last. A barista chasing balance is really adjusting time, temperature, and surface area so the extraction stops at the right point on that curve.

    The puck is a filter bed

    Grind size sets the surface area, but the puck's real job is hydraulic. Tamping compresses the grounds into a uniform filter bed with predictable resistance. If the bed is uneven, water finds the path of least resistance and carves a channel — a phenomenon called channeling — over-extracting a narrow column of coffee while leaving the rest of the puck barely touched. The result is a shot that is somehow both bitter and sour at once.

    Modern technique obsesses over puck preparation for exactly this reason: distribution tools, Weiss Distribution Technique needles, and precision baskets all exist to make the bed's permeability boring and uniform.

    Crema, an emulsion with a deadline

    The reddish-brown foam capping a fresh shot is crema: carbon dioxide trapped during roasting, released under pressure and stabilized into a foam by emulsified oils and melanoidins. It is also a freshness gauge — beans more than a few weeks past roast have out-gassed most of their CO₂ and produce a thin, fleeting crema. Contrary to café mythology, crema itself tastes mostly bitter; its value is textural and diagnostic, not flavor.

    Why ratios beat recipes

    A "double shot" means little without a brew ratio: the weight of beverage in the cup divided by the weight of dry grounds. A 1:2 ratio pulled in 25 to 30 seconds is the modern starting point — 18 grams in, 36 grams out. Tighter ratios (ristretto) concentrate texture at the cost of clarity; longer ones (lungo) trade body for extraction. Because the ratio pins down strength independently of grind and time, it is the one variable worth fixing first and adjusting last.

    Notes

    How it works

    The toolbar is host-page code, not widget UI.

    1. A debounced selectionchange listener waits for a selection inside the article.
    2. The toolbar opens in a plugin-kit createPopover anchored over the selection.
    3. Both actions call controller.setQuote({ text, sourceLabel }). That shows the quote banner above the composer.
    4. Explain this calls submitMessage(prompt). Ask about it calls focusInput().

    On the wire, the quote travels ahead of the message as a ```quoted-text source=…``` block. It is all one user turn. The agent needs no extra context plumbing.

    Integrate it

    Copy selection-explain-plugin.ts into your project. Then one call wires it up:

    import { createSelectionExplainPlugin } from "./selection-explain-plugin"; // Bundler: pass the handle returned by initAgentWidget(). createSelectionExplainPlugin({ container: "#article", controller }); // Script tag: omit controller. It attaches on persona:chat-ready, or // adopts an already-mounted widget via getAgentWidgetHandles(). createSelectionExplainPlugin({ container: "#article" });

    It is not an AgentWidgetPlugin, on purpose. Plugin hooks render UI inside the widget and never receive the controller. This toolbar lives on the page and drives the controller, so it follows the companion pattern instead.

    Customize it

    Every option, annotated:

    createSelectionExplainPlugin({ container: "#article", // element or selector, resolved lazily controller, // from initAgentWidget(); omit for script-tag installs sourceLabel: "Field Notes", // quote attribution; string or (text) => string minLength: 8, // characters before the toolbar shows shouldShow: ({ range }) => // veto selections, e.g. skip code blocks !range.commonAncestorContainer.parentElement?.closest("pre"), className: "my-toolbar", // your CSS hook on .selection-explain actions: [ // replaces the default buttons { id: "explain", label: "Explain this", mode: "send", // quotes the selection, sends prompt prompt: "Explain the highlighted passage in plain language.", }, { id: "ask", label: "Ask about it", mode: "draft", // quotes the selection, focuses the composer }, ], onAction: (action, text) => console.log(action.id, text), });

    Colors follow the --persona-* theme variables, so the toolbar matches your widget theme by default.

    Streaming

    submitMessage() returns false while a reply is streaming. The toolbar falls back to the draft flow. The staged quote stays in the composer.
