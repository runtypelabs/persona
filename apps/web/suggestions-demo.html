Suggestion customization

Pick a welcome surface

The welcome namespace owns the first-open surface: variant: "card" keeps the intro card above the transcript, "hero" centers it in the empty conversation and dismisses it on the first user message, and "none" turns it off. welcome.message adds a display-only greeting bubble at transcript position zero: it is config-derived chrome, so it never reaches getMessages(), the model, or storage, and it survives clearChat(). Starters with placement: "welcome" render inside whichever surface is active.

welcome: { variant: "hero", icon: { type: "lucide", name: "sparkles" }, title: "What should we explore?", subtitle: "I can help you configure, theme, and extend Persona.", }

Transform the data

transformSuggestions can filter, rank, reorder, or enrich both configured starters and agent-produced follow-ups. Hooks receive resolved items, so string shorthand is already expanded and every item has an effective behavior: a plain object spread is all it takes to add an icon, promote one item to primary, or switch a long prompt to fill. Transform hooks compose in plugin priority order and run before maxItems.

Own the UI

renderSuggestion receives the normalized suggestion, surface, source, variant, defaultRenderer(), and select(). Return any HTMLElement; call select() to preserve events plus send/fill behavior.

Intercept selection

onSuggestionSelect is useful for analytics, routing, or policy checks. Return false to cancel the default action. Outside plugins, persona:suggestion:selected is cancelable with event.preventDefault().

Plugin sketch

plugins: [{ id: "custom-suggestions", transformSuggestions: ({ suggestions, source }) => [...suggestions] .sort((a, b) => b.label.length - a.label.length) .map((s, i) => ({ ...s, icon: s.icon ?? iconFor(s.label), emphasis: i === 0 ? "primary" : s.emphasis, behavior: source === "agent" && s.prompt.length > 120 ? "fill" : s.behavior, })), renderSuggestion: ({ suggestion, select }) => { const card = buildCard(suggestion); card.addEventListener("click", select); return card; }, onSuggestionSelect: ({ suggestion }) => { analytics.track("suggestion_selected", suggestion); } }]
