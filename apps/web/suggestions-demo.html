Suggestion customization

Transform the data

transformSuggestions can filter, rank, reorder, or enrich both configured starters and agent-produced follow-ups. Transform hooks compose in plugin priority order and run before maxItems.

Own the UI

renderSuggestion receives the normalized suggestion, surface, source, variant, defaultRenderer(), and select(). Return any HTMLElement; call select() to preserve events plus send/fill behavior.

Intercept selection

onSuggestionSelect is useful for analytics, routing, or policy checks. Return false to cancel the default action. Outside plugins, persona:suggestion:selected is cancelable with event.preventDefault().

Plugin sketch

plugins: [{ id: "custom-suggestions", transformSuggestions: ({ suggestions }) => suggestions.filter(canShow).map(addProductContext), renderSuggestion: ({ suggestion, select }) => { const card = buildCard(suggestion); card.addEventListener("click", select); return card; }, onSuggestionSelect: ({ suggestion }) => { analytics.track("suggestion_selected", suggestion); } }]
