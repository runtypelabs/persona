Deliver, don’t interrupt

composer.streamingSubmitBehavior: "join" sends only the new user message. It does not replace the response stream or restart the active tool. Each input gets its own receipt; Stop cancels the execution separately.

Live requirements: a saved native Runtype agent, a client token for a chat surface with durable turns enabled, and an API that advertises durableRecovery.join. Proxy, flow, and older servers are not supported.

To use a real agent, set VITE_LIVE_JOIN_CLIENT_TOKEN and VITE_LIVE_JOIN_API_URL in apps/web/.env.local, then restart Vite. Use a browser-safe client token, never an API key. The Code tab’s demo URL and token are placeholders; replace them for a real integration. The simulation does not demonstrate reload durability, authorization, or server-side recovery.
