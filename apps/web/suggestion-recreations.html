Starter Prompt Recreations

Five commercial welcome states, rebuilt with public Persona config only: suggestions.starters, copy.welcomeTitle / welcomeSubtitle, and theme tokens. No plugin hooks, no CSS reaching into the widget. Each panel is a separate widget instance with its own theme.

Chip variant

ChatGPT (2025)

One centered question, no subtitle, a wrapped row of rounded category pills, and the two-row composer from the May 2025 redesign: soft shadow, 28px corners, plus and mic controls. The chips prefill a prompt stem instead of sending, so the labels stay two or three words.

No starters

Claude.ai

The minimalist school. Warm cream paper, a serif time-of-day greeting, and zero starter prompts: the strongest brands ship none, because the name already communicates capability. The recreation is the welcome tone itself.

List variant

Gemini (2025)

A vertical stack of tool-flavored prompts with the icons deleted in the 2025 simplification. Rows stay transparent until hover, the accent is blue, and clicking fills the composer for editing.

Card variant

Microsoft Copilot

The rich-card school: a two by two of icon plus short title plus muted description, the two-line pattern M365 kept after everyone else dropped it. Clicking sends the label as the message.

List variant

Perplexity

Search flavored. Hairline rows carrying full questions rather than tasks, a teal accent on offwhite paper, and a send-on-click behavior that treats every starter as a query.

What this page is testing

Every trait is config

The three presentation variants (chip, card, list), the two click behaviors (send, fill), maxItems, overflow, and per-instance theme.components.suggestion.* tokens cover the whole surveyed market. The five panels here differ only in their config object.

Zero starters is a real answer

Claude and ChatGPT have both been deleting starters. They can afford it because the brand communicates capability. An embedded widget cannot, so a strong default starter set plus a one-line scope statement stays load-bearing. Set suggestions.starters.items to an empty array to opt out: omitting it falls back to the legacy suggestionChips defaults.

Token gaps found

  • Per-item icon color is not configurable. Only emphasis: "primary" tints a glyph, and it tints the border and background with it.
  • The welcome title has no typography token of its own, so a serif greeting over sans body copy is not expressible.
  • copy.welcomeSubtitle cannot be omitted: an empty string still renders the paragraph and its top margin.
  • The gap between suggestion items is a fixed 8px. The gap token sets the space between a row's icon and its copy, not the space between rows.
  • semantic.colors.primary does not reach the send button: components.button.primary.background has to be branded separately.
  • The bundled Lucide registry has no lightbulb or chart-column.
