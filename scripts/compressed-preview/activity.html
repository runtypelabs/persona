What to check
  • Compare Reasoning layout and Reasoning details before or during a run, or after replay. V5 defaults to a collapsed row with inset details; V4 keeps its card panel. All three detail treatments use the same disclosure and chevron motion.
  • Choose Reasoning layout “Row”, Reasoning details “Panel”, and Tool rendering “Individual rows”. After Run all, expand the reasoning and a tool: their detail panels share a subtle fill, borderless 8px corners, 10px/12px inner padding, and disclosure spacing. Reasoning stays muted prose; tools keep Request/Response labels and monospace structured values. Compare inside and outside whole-turn activity.
  • Change Shared detail panel after a run, then set Green fill only for tools and 0px border only for reasoning: each override keeps the remaining shared properties. Reset panel theme restores the original subtle panels without another request. Border color only remains borderless. Compare ordinary and whole-turn details.
  • Choose a Tool rendering and switch Group summary during a run. Current action changes from “Checking the streaming documentation” to “Reading the adapter source.” Parallel tools and completed batches keep aggregate labels. Individual rows use descriptive titles independently of grouping or turn activity.
  • Stacks default to an aggregate header above their titled children. Summary only hides child details. Cards retain their normal header; Custom summaries can display the resolved title. Turn off Descriptive titles to check the generic fallback. Live calls use safe labels unless their adapter supplies titles.
  • Single-tool iterations open their details directly. An open tool stays visible when a second tool joins its group.
  • Elapsed timing is off by default. Per-tool timing omits sub-second calls. Expanded details have no duration footer. Custom summaries demonstrate authored timing; the whole-turn timer is independent. V4 card titles retain their legacy timing. Group timing measures the tool-activity span, including gaps between batches; it holds the latest measured interval when no child is running. Switch modes during a run or after completion.
  • During “Thinking between batches,” the adjacent header keeps working; finished iteration headers stay done.
  • Expand a group during the run. Its controls and tool rows should stay in place as more calls arrive.
  • Run again after completion. Old groups stay done while the new response waits for its first tool.
  • “Hide group icons” removes only header icons. Expanded child rows keep their icons.
  • “Custom summaries” uses all three context flags to show a custom working label for the latest group in this run. Earlier iteration groups stay done.
  • Change the label animation before or during a run. Thinking, individual tools, and running groups share the selected style. Custom summaries own their appearance.
  • Enable Long reasoning before a mock run, then open its reasoning details. Switch Shared overflow live between the V5 default, a custom cap, no fades, and Unlimited. Set per-kind overflow overrides to compare independent caps and fades; enable Long tool request/response to test each section separately. Reasoning compatibility height remains an explicit cap override. Check Plain/Inset/Panel and Row/Card, scroll the trace with the keyboard, and toggle it during height motion.
  • The version default uses height expansion in V5 and instant disclosure in V4. Choose an explicit expansion override, then open/close a group or child tool. Reverse it mid-motion: the transition starts from its current height. Headers stay in place while the inner content moves down 8 pixels when opening and up when closing, with a subtle fade; streamed details keep updating. Longer durations make this easier to inspect.
  • Change expansion settings mid-transition to settle immediately. Enable auto expand/collapse before a new run to check automatic tool transitions. Reduced motion makes all disclosures instant.
  • “Custom pulse” uses the loading-label hook and the Web Animations API. Reduced motion disables loading animations.
  • Choose a Thinking icon before or during a run. Custom icons stay still by default; icon animation is independent of the text effect. The diamond is registered through the public icon registry.
