What to check
  • Choose a Tool rendering and switch Group summary during a run. Current action changes from “Checking the streaming documentation” to “Reading the adapter source.” Parallel tools and completed batches keep aggregate labels. Individual rows use descriptive titles independently of grouping or turn activity.
  • Stacks default to an aggregate header above their titled children. Summary only hides child details. Cards retain their normal header; Custom summaries can display the resolved title. Turn off Descriptive titles to check the generic fallback. Live calls use safe labels unless their adapter supplies titles.
  • Single-tool iterations open their details directly. An open tool stays visible when a second tool joins its group.
  • Elapsed timing is off by default. Per-tool timing omits sub-second calls; exact milliseconds remain in expanded details. Group timing measures the tool-activity span, including gaps between batches; it holds the latest measured interval when no child is running. Switch modes during a run or after completion.
  • During “Thinking between batches,” the adjacent header keeps working; finished iteration headers stay done.
  • Expand a group during the run. Its controls and tool rows should stay in place as more calls arrive.
  • Run again after completion. Old groups stay done while the new response waits for its first tool.
  • “Hide group icons” removes only header icons. Expanded child rows keep their icons.
  • “Custom summaries” uses all three context flags to show a custom working label for the latest group in this run. Earlier iteration groups stay done.
  • Change the label animation before or during a run. Thinking, individual tools, and running groups share the selected style. Custom summaries own their appearance.
  • Choose Height expansion, then open/close a group or child tool. Reverse it mid-motion: the transition starts from its current height. Headers stay in place while the inner content moves down 8 pixels when opening and up when closing, with a subtle fade; streamed details keep updating. Longer durations make this easier to inspect.
  • Change expansion settings mid-transition to settle immediately. Enable auto expand/collapse before a new run to check automatic tool transitions. Reduced motion makes all disclosures instant.
  • “Custom pulse” uses the loading-label hook and the Web Animations API. Reduced motion disables loading animations.
  • Choose a Thinking icon before or during a run. Custom icons stay still by default; icon animation is independent of the text effect. The diamond is registered through the public icon registry.
